# История изменений дашборда СКИФ-48

Даты — по коммитам этого репозитория (отдельный git внутри `Rus-Prostor`).
Номеров версий нет: приложение публикуется с ветки `master`, для
share.streamlit.io каждая запушка — это и есть релиз.

Единое правило проверки, выведенное после трёх правок подряд, которые падали
только на хостинге: **ошибка, видимая на share.streamlit.io, не проверяется на
локальной версии Streamlit.** Перед публикацией приложение прогоняется в
изолированном окружении со свежей версией (`pip install "streamlit>=1.52,<2"`)
наравне с локальной.

## 20.10.2026

### Изменено — градиент заливки трека (`33a34dd`)

Раньше все сегменты с забитием красились одинаковым красным. Теперь цвет
зависит от числа одновременно забитых сошников по шкале 1…32: один забитый —
жёлтый `#e6b800`, дальше через оранжевый к красному на максимуме шкалы (там
цвет совпадает с прежним `COLOR_BAD`, так что худшие участки выглядят как
раньше).

Цвета интерполируются в **HSL по каналу оттенка** (48° → 3°), а не в RGB:
середина шкалы в RGB даёт грязно-коричневый, в HSL — чистый оранжевый.

Детали реализации:

- флагов `221…224` в выгрузке **32 штуки, по одному на каждый сошник** машины,
  поэтому шкала именно 0…31, а не 0…4;
- сегменты группируются по значению счётчика, а не по факту «забит/нет»:
  237 ломаных против прежних 119, сборка карты — 0.06 с на весь период
  (49 тыс. точек);
- легенда под картой — полоса градиента с подписями краёв «1 … 32», ступеней
  слишком много для набора отдельных квадратов;
- подсказки на ломаных показывают точное число забитых («забито сошников: 7»).

Проверено на Streamlit 1.51 и 1.66: подъём за 4 с, 237 ломаных, 32 оттенка,
легенда на месте.

### Исправлено — фирменный флажок Leaflet в атрибуции (`e11991d`)

Сине-жёлтый прямоугольник 12×8 px перед словом «Leaflet» в правом нижнем углу
карты — SVG `leaflet-attribution-flag`, знак самой библиотеки Leaflet (у неё
украинский автор, отсюда цвета). Он подставляется по умолчанию в **любую** карту
на Leaflet: это не выбранный нами провайдер тайлов и не наш код.

Убран вместе со ссылкой и разделителем «|»; обязательная подпись
«© OpenStreetMap contributors» остаётся — её требует лицензия ODbL.

Прячется стилями внутри карты, а не JS: streamlit-folium пересобирает JS карты
сам (`generate_leaflet_string`) и отбрасывает всё добавленное в `root.script`,
зато `root.header` и `root.html` отдаёт как есть. Стили поэтому лежат в
`root.header`.

## 19.10.2026

### Исправлено — падение на хостинге: формат даты (`8dfd0f4`)

Настоящая причина `StreamlitValueError` в `date_input` на share.streamlit.io.
Streamlit 1.66 проверяет параметр `format` по белому списку и отвергает
смешанный разделитель «точка + слэш»:

```
Invalid format value. Supported values: 'YYYY/MM/DD', 'DD/MM/YYYY', ...,
'DD.MM.YYYY', ... Provided value: 'DD.MM/YYYY'.
```

Streamlit 1.51 проверял формат регуляркой и такое пропускал — отсюда «работает
локально, падает на сервере». Исправление: `DD.MM.YYYY`, валидно в обеих
версиях.

### Исправлено — календарь: одно значение, один источник (`1946f4d`)

Начальные значения даты и времени кладутся в `session_state`, а виджеты
`date_input` / `time_input` создаются **без** `value=`. Правило: не передавать
`value=` у виджета, чей ключ уже есть в `session_state`, — на свежих версиях
Streamlit это StreamlitValueError.

Эта правка была первой догадкой на причину падения и оказалась не виноватой
(виноват формат выше), но осталась полезной: источник значения ровно один.

### Исправлено — падение фронтенда на хостинге: CSS через `st.html` (`f2ea8c5`)

Приложение задеплоивалось, но страница падала с
`NotFoundError: Failed to execute 'removeChild'`: React не мог удалить узел,
которого к моменту rerun уже не было. Виноват мой CSS для сайдбара, влитый
через `st.markdown(..., unsafe_allow_html=True)`: такой вызов прогоняет HTML
через санитайзер и подмешивает узлы в DOM, которым React управляет сам.

Заменено на штатный `st.html()`. Заодно снят потолок `streamlit<1.52` из
`requirements.txt`: он был основан на предположении о поведении `on_change`, а
на хостинге как раз мог давать расхождение версий фронтенда и python-пакета.
Колбэк выбора периода и так читает значение из `session_state`.

Проверено: вёрстка сохранена полностью (сайдбар 380 px, шесть индикаторов в
одну линию), карта рисуется, `removeChild` в консоли — 0.

### Изменено — данные клиента: исходные координаты (`4477c8c`)

`scripts/sanitize_for_public.py` переделан на сдвиг координат (±2,3 км, с
контролем выхода за допустимую зону) и сделан **необязательным** шагом.
Демонстрация идёт заказчику, и он должен видеть свои ориентиры: со сдвинутым
треком первая же претензия — «вы показываете не наше поле».

README дополнен разделом о доступе: GitHub-репозиторий держать приватным,
ссылку share.streamlit.io отправлять клиенту напрямую (закрытого варианта у
площадки нет).

### Добавлено — первая публикация (`707e8f8`)

Приложение Streamlit, набор данных `data/telemetry_skif48.csv` (49 373 точки,
39 колонок, объект 12917) и скрипты:

- `make_delta_columns.py` — дельты накопительных счётчиков с защитой от сброса
  через ноль (высокая отметка, эпохи, порог «глубже половины»);
- `build_dataset.py` — xlsx → CSV с самопроверкой инварианта
  `ΔПлощадь_га × 10000 / ΔПробег_м == ширина захвата`;
- `sanitize_for_public.py` — обезличивание для публичного показа.

CSV вместо xlsx — чтение 0,09 с против 21,6 с, на бесплатном хостинге это
разница между «открылось» и «висит».
